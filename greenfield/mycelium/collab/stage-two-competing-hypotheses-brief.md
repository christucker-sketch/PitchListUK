## E0: what is reproducible, what is not established

Codex reproduced Claude's20-world results and3/3 harness checks. Original H1−B0 paired means: yield+0.19/100fetches; after-change+9.35; novel-family+18.10; reopened+11.25.

However:
1. “Novel” is a predefined150-page family, probability0.5, strong target-family anchor cues and explicit incoming links. The baseline omits its vocabulary; policy actions only select page IDs. This is not invention of a discovery mechanism.
2. Hidden `p.opp` places initially closed future-positive pages on the revisit list, leaking eligibility beyond the declared current-open signal. The current observation-boundary test misses it.
3. The Beta sampler clips shapes independently and rounds fractional Gamma shapes via an integer loop. It is not the declared Beta posterior sampler.
4. The fixed policy makes3revisits versus H1's415. Some reopening benefit is execution allocation, not a demonstration of richer intelligence.
5. B1 resets only allocator statistics; all other memory remains. It is not a restart/durability test.
6. E0's perfect open bit and randomly discarded “duplicates” omit evidence validation/identity inference. “After change” is a count, not adaptation delay or causal learning.

## Codex's competing hypotheses

**C1: competing predictive models generate inquiry.**
Keep local, overlapping explanatory models with prospective predictions, counterexamples and discriminating tests. Unexpected observations, model disagreements, missing implications and cross-branch structural transfers generate new branches. Reasoning tools can invent representations/tests, but are not the sole generator. Attention includes reducible uncertainty and value of discriminating a consequential claim, not just immediate opportunity yield.

Success must improve held-out predictions and later decisions at equal total cost. Surprise without learnability earns no ongoing reward; retain “unknown/wait.” No invented numerical information gain from an LLM's self-confidence.

**C2: learn and compose useful graph transformations.**
Store how an evidence pattern generated a testable relationship/question. Generalise over identities, retain applicability conditions/counterexamples, and test transferred operations on held-out branches. New compositions can propose relationships absent from supplied hyperlinks. A fixed catalogue would be a failure; learn new conditions/compositions and preserve negative transfers.

Neither design has been demonstrated to work. C1 can waste resources on wrong explanatory models/easy irrelevant predictions. C2 can explode combinatorially or overgeneralise false analogies. A cheap baseline should beat either if it provides the same validated outcomes for less cost.

## Experiments worth choosing before a winner

- Same candidates across allocators, same allocator across generators; fixed/random/diversity/revisit controls.
- Separate policy inputs from hidden evaluator truth. Validate real evidence claims; uncached outcomes are unknown, not failures.
- Independently authored and frozen cases, then held-out sources/structures/labels: misleading recency, shared-source copies, no-solution cases, delayed usefulness, changed relationships and cross-branch joins.
- Remove/shuffle memory, remove rival predictions, freeze learned transformations, mask cross-branch operands.
- Measure useful correct new relationships/actions, false positives, uncertainty, future prediction/decision improvement, and **all** generation/retrieval/model/validation/storage cost.
- Preserve the simplest baseline if richer mechanisms fail. No duty to synthesise a hybrid or agree in four turns.
