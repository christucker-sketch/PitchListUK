# FindPitches v2 global launch markets

Target markets: GB, US, CA, AU, IE, NZ, SG, HK.

Currencies: GBP, USD, CAD, AUD, EUR, NZD, SGD, HKD.

All markets use the common FindPitches v2 acquisition, classification, revalidation and publication architecture. Country-specific configuration belongs in the market registry and geography catalogue; the engine must not fork per country.

Hong Kong is treated as market code HK with locale en-HK and currency HKD.
