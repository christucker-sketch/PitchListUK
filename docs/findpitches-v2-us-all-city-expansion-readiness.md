# FindPitches v2 — US all-city coverage expansion, staged behind venue evidence recovery

## Verified geographic planning baseline (29 September 2026)

The existing first-run, SHA-256-pinned offline index joins 2025 Census places to 2020 Census population. It covers all 50 states, **32,057 places**, **19,497 incorporated places**, 12,540 CDPs and 20 special/unclassified entries. It contains 314 population-matched incorporated >=100k places and seven populous special-government units for separate review. It also carries 37 incorporated places with unresolved population. Mixed vintage is explicit; never silently declare a final major-city denominator.

These figures describe the geographic reference **only**, not discovered or customer-ready opportunities. The 29 Sep 20:34 BST source-backed US audit found 352 code-visible records, 31 independently verified historic venue records covering 29 Census places and 321 unresolved. A separately corroborated St Clair Shores venue remains pending revision/application validation. A later strict stored-text snapshot showed 8 of the original 31 cases meeting the stricter predicate, with 23 queued for historical reinspection. Do not treat a strict-text miss as an invalid event.

## Workstream order (not a global acquisition pause)

1. **Finish bounded known-source recovery.** The first 23 historical missing-strict-evidence cases were sampled in two completed read-only batches. No historical venue was automatically revoked or promoted. The wider unresolved US cohort is now supported by a single immutable snapshot, serial 12-record checkpoints, per-host request budget/cooldown, socket-level public DNS pinning and no redirects. Outcome categories distinguish candidate venue text, inspected pages without proof, all sources failed, no safe sources, oversized sources and other fetch failures. Store results in a private operator artifact; review current event edition, deadline, duplicate and exact venue. No Serper is needed for this known-source phase.
2. **Make a precision/recall fixture set.** Re-examine the original verified venues whose current snippets fail strict extraction. Record exact current event-source excerpts and revision IDs for each real venue, then measure new strict parser precision and false-negative rate against these before changing historical customer visibility. Large HTML pages, extracted PDF page limits, obsolete years and redirected official applications need separate bounded follow-up.
3. **Establish trusted per-place visibility.** Merge only independently confirmed event venue GEOIDs from currently visible, current-revision, nonduplicate records into a place-level planning snapshot. Old discovery state, organiser office, proximity and unknown locations do NOT create Census matches. If any currently visible US record remains unverified, the national city-level zero-coverage snapshot is incomplete; classify unmeasured places as UNKNOWN rather than reporting zero.
4. **Stage all-city search generation on v2 only.** The new offline `planUsCityGapFill()` uses the full imported place index as its addressable universe. It chooses an initial seed in each state, then other high-population incorporated places, special-government cases, regional hubs and smaller towns. Census CDPs are tracked separately by default; unresolved population is not fabricated. Suggested festival/fair/vendor and farmers-market queries are **plan text**, not executed Serper calls. Extend later with authoritative county/metro mapping and reusable statewide organisers rather than blindly spending one search on each of 19,497 cities.
5. **Integrate cost/yield-driven gap filling without stopping baseline acquisition.** Once recovery fixtures, dedupe and venue accuracy meet reviewed thresholds, add a separate v2 discovery lane that tracks per-source search cost, new current-ready unique opportunities, official vendor application evidence, place breadth and retry policy. Cycle low-coverage states and cities over time. No v1 workflow, DNS, public routes, v2 publication flag or Cloudflare scheduler is altered by the present planning commits.

## Operational invariants

- v1 is completely untouched. V2 publication remains disabled; private read-only recovery must use the isolated v2 D1 identifier and fail if /health no longer advertises isolated shadow mode.
- Operators review source venue, **current year/event dates**, application acceptance/deadline, suspected same-source duplicates (including Washta) and Census boundary type before attaching a verified place.
- Full source sweeps are bounded and resumable from a saved private artifact. Record a stable candidate revision with each result; a stale historical review without a revision stamp remains comparison-only.
- Never equate acquiring in a state with hosting in that state (the VA-to-Atlanta and AR-to-Orlando historical cases proved the risk). County fairgrounds outside an incorporated city belong to their actual place/county geography, not the search term's city.
