# Handover entry template

Append an entry to `team/HANDOVERS.md`; do not replace earlier entries. Identify the actual author, recipient/task, timestamp and source of any approval.

```markdown
## <London timestamp with offset> — <author> → <recipient/task>

Completed / changed behaviour:
Task IDs and ownership being handed over:
Evidence links and pushed Git SHA:
Actual deployment version/environment, or “not deployed”:
Validation and practical limitations:
Metrics snapshot timestamp and scope:
Blockers / missing capabilities:
Next concrete action and owner:
Approvals already provided / exact remaining gate:
Spend, messages, publication, production and preservation outcomes:
Incoming contributor acknowledgement: pending / link to actual update
```

Do not mark a recipient notified or acknowledged without their actual update. Use sanitized evidence. Private credentials/customer/source material stay outside GitHub.
